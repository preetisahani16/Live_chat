# 3-minute pitch

**Problem:** S2B clients wait for agents, live support is limited to operating hours, assisted contacts add cost, and external products may not satisfy bank governance.

**Solution:** An in-house AI voice agent that answers common service queries 24×7 using approved knowledge. It masks sensitive data, refuses transaction execution, shows confidence and source, and creates a human-support ticket when needed.

**Demo:** Login → voice password-reset query → pending-payment query → prohibited transfer request → compliance block and ticket → operations dashboard.

**Value:** Reduced vendor/support cost, no waiting for common queries, governed data handling, auditable conversations, and improved agent productivity.

**Next:** Multilingual speech, production authentication, country-specific knowledge, CRM/ServiceNow integration, sentiment detection, monitoring and model governance.
